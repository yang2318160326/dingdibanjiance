## 1. 系统概述

### 1.1 项目背景

本系统用于工业/环境场景下的远程数据采集，由**多个STM32下位机**（数据采集终端）和**一个安卓APP上位机**（数据管理终端）组成。每个下位机连接**一个传感器**，独立完成数据的定时采集和存储。上位机通过蓝牙**依次**连接各个下位机，完成参数配置和数据下载。

### 1.2 系统拓扑

```
                         ┌─────────────┐
                         │  安卓手机    │
                         │  上位机APP   │
                         └──────┬──────┘
                                │ BLE (手动切换连接)
                    ┌───────────┼───────────┐
                    │           │           │
                    ▼           ▼           ▼
             ┌──────────┐ ┌──────────┐ ┌──────────┐
             │ 下位机 #1 │ │ 下位机 #2 │ │ 下位机 #N │
             │ STM32    │ │ STM32    │ │ STM32    │
             └────┬─────┘ └────┬─────┘ └────┬─────┘
                  │            │            │
             ┌────▼─────┐ ┌────▼─────┐ ┌────▼─────┐
             │ 传感器 #1 │ │ 传感器 #2 │ │ 传感器 #N │
             │ (RS485)   │ │ (RS485)   │ │ (RS485)   │
             └──────────┘ └──────────┘ └──────────┘
```

### 1.3 操作流程

```
用户手持手机, 依次操作各台下位机:

1. 走近1号下位机
2. 打开APP, 扫描BLE设备
3. 连接1号下位机
4. 设置参数 (采样间隔等)
5. 同步时间
6. 下载已存储的数据
7. 手动断开BLE连接
8. 走近2号下位机
9. 重复步骤2-7
... 依次完成所有下位机
```

### 1.4 系统功能清单

| 编号 | 功能 | 所属端 | 说明 |
|------|------|--------|------|
| F01 | RS485传感器数据采集 | 下位机 | 通过Modbus RTU协议读取单个传感器 |
| F02 | 定时采集调度 | 下位机 | 支持0~24小时间隔，0为连续采集 |
| F03 | 低功耗睡眠 | 下位机 | 非采集时段进入STOP2模式，RTC闹钟唤醒 |
| F04 | 数据本地存储 | 下位机 | Flash环形缓冲，掉电不丢失 |
| F05 | 蓝牙通信 | 双向 | BLE透传，自定义帧协议 |
| F06 | 多设备管理 | 上位机 | 支持依次连接多个下位机 |
| F07 | 参数配置 | 上位机 | 采样间隔、传感器参数、时间同步 |
| F08 | 数据下载 | 上位机 | 从当前连接设备下载数据，支持断点续传 |
| F09 | 多设备数据隔离 | 上位机 | 每台设备数据独立存储，按设备ID区分 |
| F10 | 数据可视化 | 上位机 | 折线图展示历史数据，支持按设备筛选 |
| F11 | 数据导出 | 上位机 | 按设备导出CSV/JSON文件 |

## 2. 硬件概述

### 2.1 下位机硬件框图 (每台设备相同)

```
                    ┌─────────────────────────────┐
                    │        STM32L476RG           │
                    │                              │
  [RS485传感器] ────┤ UART2 ──┐                    │
  (单个传感器)      │         │                    │
                    │    ┌────▼────┐               │
                    │    │MAX3485  │               │
                    │    │(收发器) │               │
                    │    └─────────┘               │
                    │                              │
  [HC-08蓝牙] ─────┤ UART1                       │
                    │                              │
                    │    ┌─────────┐               │
                    │    │ RTC     │── LSE 32.768K │
                    │    └─────────┘               │
                    │                              │
  [LED] ───────────┤    GPIO                      │
  [按键] ──────────┤    GPIO                      │
                    │                              │
                    │    Flash:                    │
                    │    ├─ 应用代码               │
                    │    ├─ 配置页                 │
                    │    ├─ 数据页A/B              │
                    │    └─ 元数据页               │
                    └─────────────────────────────┘
```

### 2.2 关键器件选型

| 器件 | 型号 | 说明 |
|------|------|------|
| MCU | STM32L476RG | Cortex-M4, 80MHz, 1MB Flash, STOP2: 3-8μA |
| RS485收发器 | MAX3485 | 3.3V, 半双工 |
| 蓝牙模块 | HC-08 / BT02 | BLE 4.2, UART透传 |
| 晶振 | 8MHz HSE + 32.768KHz LSE | 主时钟 + RTC |

### 2.3 引脚分配

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA2 | USART2_TX | RS485发送 |
| PA3 | USART2_RX | RS485接收 |
| PA4 | RS485_DE | 方向控制 |
| PA9 | USART1_TX | 蓝牙模块TX |
| PA10 | USART1_RX | 蓝牙模块RX |
| PB0 | LED_STATUS | 状态指示灯 |
| PB1 | LED_BLE | 蓝牙连接指示灯 |
| PC13 | KEY_WAKE | 唤醒/配置按键 |

## 3. 下位机配置模型 (简化)

### 3.1 与旧方案的差异

```
旧方案 (多传感器):                  新方案 (单传感器):
┌─────────────────────┐            ┌─────────────────────┐
│ SystemConfig_t      │            │ SystemConfig_t      │
│ ├─ sampling_interval│            │ ├─ sampling_interval│
│ ├─ sensor_count = 5 │            │ ├─ sensor_count = 1 │ ← 固定为1
│ ├─ sensors[0]       │            │ ├─ sensor           │ ← 单个传感器配置
│ ├─ sensors[1]       │            │ ├─ modbus_baudrate  │
│ ├─ sensors[2]       │            │ └─ modbus_parity    │
│ ├─ sensors[3]       │            └─────────────────────┘
│ ├─ sensors[4]       │
│ ├─ modbus_baudrate  │
│ └─ modbus_parity    │
└─────────────────────┘
```

### 3.2 简化后的配置结构

```c
typedef struct __attribute__((packed)) {
    uint32_t magic;                     // 0x434F4E46
    uint32_t version;
    uint32_t device_id;                 // 设备唯一ID
    char     device_name[16];           // 设备名称
    uint32_t sampling_interval_sec;     // 采样间隔 (秒), 0=连续
    /* 单传感器配置 (不再需要传感器表) */
    uint8_t  sensor_addr;               // 传感器Modbus地址 (1-247)
    uint16_t sensor_start_reg;          // 起始寄存器地址
    uint16_t sensor_reg_count;          // 读取寄存器数量 (1-125)
    uint8_t  sensor_data_type;          // 数据类型
    /* 通信参数 */
    uint32_t modbus_baudrate;           // 波特率 (默认9600)
    uint8_t  modbus_parity;             // 校验位
    uint16_t crc16;
} SystemConfig_t;                       // 约40字节
```

## 4. 上位机多设备管理

### 4.1 设备管理模型

```
┌─────────────────────────────────────────────────┐
│                 APP 设备管理                     │
│                                                 │
│  已知设备列表 (本地持久化):                      │
│  ┌─────────────────────────────────────────────┐│
│  │ #1  ID:A1B2  名称:温度采集器1  上次:06-03  ││
│  │ #2  ID:C3D4  名称:湿度采集器2  上次:06-02  ││
│  │ #3  ID:E5F6  名称:压力采集器3  上次:06-01  ││
│  └─────────────────────────────────────────────┘│
│                                                 │
│  当前连接:                                      │
│  ┌─────────────────────────────────────────────┐│
│  │ 🟢 已连接: 温度采集器1 (A1B2)               ││
│  │    信号: -65dBm                             ││
│  │    [断开] [配置] [下载数据]                  ││
│  └─────────────────────────────────────────────┘│
│                                                 │
│  操作流程:                                      │
│  1. 扫描 → 2. 选择设备 → 3. 连接               │
│  → 4. 操作(配置/下载) → 5. 断开 → 6. 重复      │
└─────────────────────────────────────────────────┘
```

### 4.2 数据隔离策略

每台设备的数据通过 `deviceId` (设备MAC地址或自定义ID) 隔离:

```
Room数据库:
┌──────────────────────────────────────────────────────┐
│ sensor_records 表                                     │
│                                                      │
│ id │ deviceId │ timestamp │ sensorAddr │ status │ ...│
│ ───┼──────────┼───────────┼────────────┼────────┼────│
│  1 │ AA:BB:.. │ 1717500000│     1      │   0    │    │ ← 设备1的数据
│  2 │ AA:BB:.. │ 1717500060│     1      │   0    │    │ ← 设备1的数据
│  3 │ CC:DD:.. │ 1717500120│     2      │   0    │    │ ← 设备2的数据
│  4 │ CC:DD:.. │ 1717500180│     2      │   1    │    │ ← 设备2的数据
└──────────────────────────────────────────────────────┘
```

### 4.3 导出按设备分组

```
导出时可选择:
○ 仅当前连接的设备
○ 指定设备 (从列表选择)
○ 全部设备

文件命名自动包含设备ID:
  data_AABBCCDD_20260604_103000.csv   ← 设备1
  data_11223344_20260604_110000.csv   ← 设备2
```

## 5. 工作模式

### 5.1 下位机工作模式 (与旧方案相同)

| 模式 | 进入条件 | 功耗 | 说明 |
|------|----------|------|------|
| 运行模式 | RTC闹钟唤醒 | ~10mA | 读传感器、写Flash |
| STOP2睡眠 | 采集完成 | ~3-8μA | 仅RTC运行 |
| BLE活动模式 | APP连接 | ~15mA | 运行模式 + BLE |
| 连续采集模式 | interval=0 | ~10mA | 不进入睡眠 |

### 5.2 上位机工作状态 (新增多设备状态)

```
┌──────────┐  扫描   ┌──────────┐  选择   ┌──────────┐

│          │        │          │        │  设备列表│
└──────────┘        └──────────┘        └────┬─────┘
     ▲                                       │ 连接
     │ 断开                                   ▼
     │                                 ┌──────────┐
     │                                 │  已连接  │
```
