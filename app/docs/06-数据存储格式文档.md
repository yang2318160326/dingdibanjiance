## 1. 概述

```
设备端 (STM32 Flash)          手机端 (Room + 文件)
┌─────────────────┐           ┌─────────────────────┐
│ 单设备数据      │  BLE传输  │ 多设备数据          │
│ ┌─────────────┐ │ ────────▶ │ ┌─────────────────┐ │
│ │ 配置页      │ │           │ │ known_devices   │ │
│ │ (单传感器)  │ │           │ │ (设备列表)      │ │
│ ├─────────────┤ │           │ ├─────────────────┤ │
│ │ 数据页A/B   │ │           │ │ sensor_records  │ │
│ │ (环形缓冲)  │ │           │ │ (按deviceId分)  │ │
│ ├─────────────┤ │           │ ├─────────────────┤ │
│ │ 元数据页    │ │           │ │ device_configs  │ │
│ └─────────────┘ │           │ │ (每设备配置)    │ │
└─────────────────┘           │ ├─────────────────┤ │
                              │ │ CSV/JSON导出    │ │
                              │ └─────────────────┘ │
                              └─────────────────────┘
```

## 2. 设备端存储格式 (STM32 Flash)

### 2.1 Flash布局

```
地址范围                    内容              大小
──────────────────────────────────────────────────
0x08000000 - 0x0803FFFF     应用代码          256KB
0x08040000 - 0x080407FF     配置页            2KB
0x08040800 - 0x080447FF     数据页A           16KB (512条)
0x08044800 - 0x080487FF     数据页B           16KB (512条)
0x08048800 - 0x08048FFF     元数据页          2KB
```

### 2.2 传感器数据记录 (SensorRecord_t)

```
偏移    长度    字段名          类型        说明
──────────────────────────────────────────────────────────────
0x00    4B      timestamp       uint32_t    Unix时间戳, 大端序
0x04    1B      sensor_addr     uint8_t     传感器地址 (来自配置, 固定值)
0x05    1B      status          uint8_t     状态码
0x06    2B      reg_count       uint16_t    寄存器数量, 大端序
0x08    2B      reg_values[0]   uint16_t    寄存器值0
0x0A    2B      reg_values[1]   uint16_t    寄存器值1
0x0C    2B      reg_values[2]   uint16_t    寄存器值2
0x0E    2B      reg_values[3]   uint16_t    寄存器值3
0x10    2B      reg_values[4]   uint16_t    寄存器值4
0x12    2B      reg_values[5]   uint16_t    寄存器值5
0x14    2B      reg_values[6]   uint16_t    寄存器值6
0x16    2B      reg_values[7]   uint16_t    寄存器值7
0x18    4B      sequence_num    uint32_t    单调递增序号
0x1C    2B      crc16           uint16_t    CRC16 (字节0x00~0x1B), 小端序
0x1E    2B      reserved        uint16_t    保留
──────────────────────────────────────────────────────────────
总计    32B
```

状态码: 0=OK, 1=超时, 2=CRC错误, 3=Modbus异常

### 2.3 系统配置 (SystemConfig_t) -- 单传感器版

```
偏移    长度    字段名              类型        说明
──────────────────────────────────────────────────────────────
0x00    4B      magic               uint32_t    0x434F4E46
0x04    4B      version             uint32_t    版本号
0x08    4B      device_id           uint32_t    设备ID
0x0C    16B     device_name         char[16]    设备名称
0x1C    4B      sampling_interval   uint32_t    采样间隔 (秒)
0x20    1B      sensor_addr         uint8_t     传感器Modbus地址
0x21    2B      sensor_start_reg    uint16_t    起始寄存器
0x23    2B      sensor_reg_count    uint16_t    寄存器数量
0x25    1B      sensor_data_type    uint8_t     数据类型
0x26    4B      modbus_baudrate     uint32_t    波特率
0x2A    1B      modbus_parity       uint8_t     校验位
0x2B    2B      crc16               uint16_t    校验
──────────────────────────────────────────────────────────────
总计    约45字节 (填充到2KB Flash页)
```

### 2.4 环形缓冲元数据 (StoreMetadata_t)

```
偏移    长度    字段名          类型        说明
──────────────────────────────────────────────────
0x00    4B      magic           uint32_t    0x44415441
0x04    4B      version         uint32_t    1
0x08    4B      head_index      uint32_t    写入位置
0x0C    4B      tail_index      uint32_t    最旧记录
0x10    4B      total_records   uint32_t    有效记录数
0x14    4B      total_capacity  uint32_t    最大容量
0x18    2B      crc16           uint16_t    校验
──────────────────────────────────────────────────
总计    26B (填充到32B)
```

## 3. 手机端存储格式

### 3.1 已知设备表 (known_devices)

```kotlin
@Entity(tableName = "known_devices")
data class DeviceEntity(
    @PrimaryKey
    val macAddress: String,         // BLE MAC地址 (唯一标识)
    val customName: String,         // 用户自定义名称
    val deviceId: Long,             // 设备端ID
    val firstSeen: Long,            // 首次连接时间
    val lastConnected: Long,        // 最后连接时间
    val recordCount: Int,           // 本地记录数
    val notes: String               // 备注
)
```

示例数据:
```
macAddress      | customName    | deviceId | firstSeen      | lastConnected  | recordCount
----------------|---------------|----------|----------------|----------------|------------
AA:BB:CC:DD:EE:FF| 温度采集器1   | 1        | 1717400000000  | 1717500000000  | 1234
11:22:33:44:55:66| 湿度采集器2   | 2        | 1717300000000  | 1717450000000  | 567
AA:11:BB:22:CC:33| 压力采集器3   | 3        | 1717200000000  | 1717350000000  | 890
```

### 3.2 传感器记录表 (sensor_records)

```kotlin
@Entity(tableName = "sensor_records")
data class RecordEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,
    val deviceId: String,          // BLE MAC地址 (关联到known_devices)
    val timestamp: Long,           // Unix时间戳
    val sensorAddress: Int,        // 传感器地址
    val status: Int,               // 状态码
    val registerValues: String,    // JSON: "[2345,6789,1234,5678]"
    val sequenceNum: Long,         // 设备端序号
    val downloadedAt: Long         // 下载时间
)
```

示例数据:
```
id | deviceId       | timestamp  | sensorAddr | status | registerValues      | seq  | downloadedAt
---|----------------|------------|------------|--------|---------------------|------|-------------
1  | AA:BB:CC:DD:EE:FF| 1717500000 | 1          | 0      | [2345,6789,1234,5678] | 1001 | 1717500100000
2  | AA:BB:CC:DD:EE:FF| 1717500060 | 1          | 0      | [2346,6790,1235,5679] | 1002 | 1717500100000
3  | 11:22:33:44:55:66| 1717500120 | 2          | 0      | [9876,5432]           | 2001 | 1717500200000
4  | 11:22:33:44:55:66| 1717500180 | 2          | 1      | [0,0]                 | 2002 | 1717500200000
```

### 3.3 设备配置表 (device_configs)

```kotlin
@Entity(tableName = "device_configs")
data class ConfigEntity(
    @PrimaryKey
    val deviceId: String,          // BLE MAC地址
    val configJson: String,        // 配置JSON
    val savedAt: Long
)
```

configJson示例:
```json
{
    "samplingIntervalSec": 60,
    "sensorAddr": 1,
    "sensorStartReg": 0,
    "sensorRegCount": 4,
    "sensorDataType": 0,
    "modbusBaudrate": 9600,
    "modbusParity": 0
}
```

## 4. 文件导出格式

### 4.1 CSV格式

#### 文件命名

```
data_{设备MAC或ID}_{YYYYMMDD}_{HHmmss}.csv

示例:
data_AABBCCDD_20260604_103000.csv    ← 温度采集器1
data_11223344_20260604_110000.csv    ← 湿度采集器2
```

#### 文件内容

```csv
# 设备MAC: AA:BB:CC:DD:EE:FF
# 设备名称: 温度采集器1
# 设备ID: 1
# 传感器地址: 1
# 导出时间: 2026-06-04 10:30:00
# 记录总数: 1234
device_id,timestamp,datetime,sensor_address,status,status_text,reg_0,reg_1,reg_2,reg_3,reg_4,reg_5,reg_6,reg_7,sequence
AABBCCDD,1717500000,2026-06-04 10:00:00,1,0,OK,2345,6789,1234,5678,0,0,0,0,1001
AABBCCDD,1717500060,2026-06-04 10:01:00,1,0,OK,2346,6790,1235,5679,0,0,0,0,1002
```

### 4.2 JSON格式

```json
{
    "device_info": {
        "mac_address": "AA:BB:CC:DD:EE:FF",
        "device_id": 1,
        "device_name": "温度采集器1",
        "firmware_version": "1.02",
        "sensor_address": 1
    },
    "export_info": {
        "export_time": "2026-06-04T10:30:00+08:00",
        "app_version": "1.0.0",
        "record_count": 1234
    },
    "records": [
        {
            "timestamp": 1717500000,
            "datetime": "2026-06-04T10:00:00+08:00",
            "sensor_address": 1,
            "status": 0,
            "status_text": "OK",
            "registers": [2345, 6789, 1234, 5678, 0, 0, 0, 0],
            "sequence": 1001
        }
    ]
}
```

### 4.3 多设备导出

当选择导出多台设备时, 为每台设备生成独立文件:

```
导出操作 → 选择3台设备 → 生成3个文件:
  data_AABBCCDD_20260604_103000.csv
  data_11223344_20260604_103000.csv
  data_AA11BB22_20260604_103000.csv
```

## 5. 容量计算

### 5.1 设备端

```
数据空间: 32KB (页A+页B)
每条记录: 32字节
最大记录: 1024条

单传感器采集 (比多传感器更省空间):
┌──────────────┬────────────┬──────────────────┐
│ 采样间隔     │ 记录/天    │ 可存储天数        │
├──────────────┼────────────┼──────────────────┤
│ 1分钟        │ 1,440条    │ 不到1天           │
│ 5分钟        │ 288条      │ 3.5天             │
│ 10分钟       │ 144条      │ 7天               │
│ 30分钟       │ 48条       │ 21天              │
│ 1小时        │ 24条       │ 42天              │
│ 2小时        │ 12条       │ 85天              │
│ 6小时        │ 4条        │ 256天             │
│ 12小时       │ 2条        │ 512天             │
│ 24小时       │ 1条        │ 1024天            │
└──────────────┴────────────┴──────────────────┘
```

### 5.2 手机端

Room数据库理论容量取决于手机存储空间, 通常可存储数十万条记录。
