# 定时板卡数据采集系统

> 基于BLE通信的多设备工业数据采集方案

---

## 项目概述

本项目是一套完整的工业数据采集系统，由**STM32下位机**和**安卓APP**两部分组成，通过BLE蓝牙通信实现数据传输。

### 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    安卓APP (主机)                        │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ BLE扫描  │  │ 设备连接 │  │ 数据管理 │  │ 数据导出 │   │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘   │
│       └────────────┼───────────┼───────────┘           │
│                    ▼                                   │
│              BLE通信层                                  │
└────────────────────┬────────────────────────────────────┘
                     │ BLE 4.2 (UART透传)
┌────────────────────┴────────────────────────────────────┐
│                    STM32下位机 (从机)                    │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ BLE模块  │  │ RS485   │  │ Flash   │  │ RTC时钟  │   │
│  │ HC-08    │──│ Modbus  │──│ 环形存储 │  │         │   │
│  └─────────┘  └────┬────┘  └─────────┘  └─────────┘   │
│                    │                                    │
│              485总线接口                                │
└────────────────────┬────────────────────────────────────┘
                     │ RS485
┌────────────────────┴────────────────────────────────────┐
│                  485位移传感器 (从机)                    │
└─────────────────────────────────────────────────────────┘
```

### 硬件规格

| 组件 | 型号 | 说明 |
|------|------|------|
| 主控芯片 | STM32L476RG | 低功耗MCU, 256KB Flash |
| BLE模块 | HC-08/BT02 | 蓝牙4.0透传模块 |
| 通信接口 | RS485 | Modbus RTU协议 |
| 传感器 | 485位移传感器 | Modbus从站 |
| 电池 | 锂电池 | 低功耗设计 |

## 软件功能

### 安卓APP功能

#### 1. 设备扫描与连接
- BLE设备自动扫描
- 显示设备名称、MAC地址、信号强度(RSSI)
- 支持多设备管理，历史设备记录
- 一键连接/断开

#### 2. 设备信息查看
- 设备ID、固件版本
- 存储状态（已记录/总容量）
- 采集状态（空闲/采集中/传输中/睡眠）
- 电池电量

#### 3. 日常使用设置
- **分机号设置**: 0-99编号
- **采集间隔**: 小时:分钟格式
- **启动/停止采集**: 一键控制
- **时间同步**: 手机时间→下位机
- **清除数据**: 带确认的安全删除

#### 4. 调试设置
- **通信参数配置**: Modbus波特率、校验位
- **传感器参数**: 从站地址、寄存器配置
- **原始命令发送**: 手动发送485 Modbus指令
- **设备重启**: 远程重启下位机

#### 5. 数据管理
- 数据下载（支持断点续传）
- 数据列表显示
- 实时数据图表

#### 6. 数据导出
- CSV格式导出
- JSON格式导出
- 按设备/时间筛选
- 一键分享

### 下位机功能

#### 1. 数据采集
- 支持Modbus RTU协议
- 可配置采集间隔
- 低功耗睡眠模式

#### 2. 数据存储
- Flash环形缓冲存储
- 最大1024条记录
- 断电数据保护

#### 3. BLE通信
- 自定义帧协议
- CRC16校验
- 分块数据传输
- 错误重传机制

## 编译与安装

### 环境要求
- Android Studio 或 Cursor编辑器
- JDK 17+
- Android SDK 34
- Gradle 8.5

### 编译步骤
```bash
# 进入项目目录
cd androidapp

# 编译Debug版本
./gradlew assembleDebug

# APK输出位置
# app/build/outputs/apk/debug/app-debug.apk
```

### 安装到手机
```bash
# 通过ADB安装
adb install app/build/outputs/apk/debug/app-debug.apk

# 或直接将APK传到手机安装
```

## BLE通信协议

### 帧格式
```
+------+--------+--------+---------+----------+----------+-----+
| SOF  | SEQ    | CMD    | LEN     | PAYLOAD  | CRC      | EOF |
| 1B   | 1B     | 1B     | 2B      | 0~237B   | 2B       | 1B  |
| 0xAA | 00-FF  | 命令码 | 大端序  | 可变     | Modbus   | 0x55|
+------+--------+--------+---------+----------+----------+-----+
```

### 命令集
| CMD | 名称 | 说明 |
|-----|------|------|
| 0x01 | PING | 设备探测 |
| 0x02 | GET_INFO | 获取设备信息 |
| 0x03 | SET_TIME | 时间同步 |
| 0x04 | GET_CONFIG | 读取配置 |
| 0x05 | SET_CONFIG | 写入配置 |
| 0x06 | GET_DATA | 请求数据 |
| 0x07 | DATA_ACK | 数据确认 |
| 0x08 | ERASE_DATA | 擦除数据 |
| 0x09 | GET_STATUS | 获取状态 |
| 0x0A | SET_DEVICE_ID | 设置设备ID |
| 0x0B | REBOOT | 重启设备 |
| 0xFE | DATA_FRAG | 数据分片 |
| 0xFF | ERROR | 错误通知 |
